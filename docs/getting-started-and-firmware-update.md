# MeowKit，准备好了

这份指南带你完成第一次开机，并在需要时更新固件。

更新不会改动 microSD 卡里的文件。开始前，请保存正在进行的操作。

## 第一次使用

1. 插入 microSD 卡（可选）。
2. 打开 MeowKit 的电源。
3. 等待主屏幕出现。

现在可以开始探索了。需要连接电脑传输 microSD 卡文件时，在 MeowKit 中打开 **Settings > USB Drive**，完成后先选择 **Eject**，再拔下 USB 线。

> MeowKit 只有一个 USB 接口。文件传输、USB 功能和固件更新共用这个接口，不能同时使用。

## 更新固件

### 你需要

- 一台 Windows、macOS 或 Linux 电脑
- 一根支持数据传输的 USB 线
- 最新版 Chrome 或 Edge
- 电量不少于 30% 的 MeowKit

有些 USB 线只能充电。如果电脑始终找不到设备，先换一根确定能传数据的线。

### 开始更新

1. 在电脑上打开 **MeowKit Firmware Installer**：`https://<你的固件更新网址>`。
2. 关闭 MeowKit，并拔下 USB 线。
3. 按住 **BOOT**，同时打开电源。继续按住约 2 秒，然后松开。
4. 用 USB 线将 MeowKit 连接到电脑。
5. 在网页中选择 **连接 MeowKit**，选中刚出现的设备端口。
6. 选择 **安装**。看到“更新完成”前，不要关闭页面、关闭设备或拔线。
7. 更新完成后拔下 USB 线，关闭 MeowKit，再正常开机。

进入下载模式时，屏幕可能保持黑屏。这是正常的。

### 如果没有看到设备端口

按顺序试一次：

1. 拔下 USB 线并关闭 MeowKit。
2. 换一个电脑 USB 接口；不要使用扩展坞。
3. 换一根支持数据传输的 USB 线。
4. 重新执行“按住 BOOT、打开电源、等待 2 秒、松开、再连接电脑”。
5. 关闭可能占用串口的软件，例如 PlatformIO 串口监视器。

仍然没有端口时，换一台电脑重试。

### 如果更新中断

MeowKit 不会因此损坏。关闭设备，重新进入下载模式，再安装一次。固件写入完成前，设备可能无法正常启动。

### 设置和文件

- microSD 卡中的文件会保留。
- 通常会保留设备设置；恢复安装可能会清除设置。
- 重要文件仍建议提前备份。

## 产品实现方案

上面的流程是 MeowKit 面向用户的主路径。以下内容供产品、固件和发布团队使用。

### 1. 主路径：浏览器安装器

提供一个 HTTPS 固件安装页，基于 Web Serial 与 `esptool-js`。页面只保留三个主要动作：

1. 展示进入下载模式的短动画。
2. **连接 MeowKit**。
3. **安装 / 重新安装**。

安装器应自动识别 ESP32-S3、选择稳定版固件、校验镜像并显示真实进度。不要让普通用户选择波特率、Flash 地址、分区表或 `.bin` 文件。

建议在页面中提供两个入口：

- **更新**：不擦除 NVS，尽量保留设置。
- **恢复**：整片擦除后重装，仅在设备无法启动或更新反复失败时显示。

Safari 和 Firefox 不支持主流程时，页面应直接提示改用 Chrome 或 Edge，而不是让用户停在不可操作的界面。

### 2. 发布物：一个版本，一个可信来源

每个稳定版本至少发布：

- Web 安装器 manifest
- 分段固件镜像及 SHA-256 校验值
- 离线恢复包（Windows、macOS/Linux 各一份简短脚本或命令）
- 版本号、发布日期和三到五条用户可读的更新说明

网页安装建议按地址写入分段镜像，避开 NVS 区域：

| 地址 | 镜像 | 说明 |
| ---: | --- | --- |
| `0x0000` | `bootloader.bin` | ESP32-S3 bootloader |
| `0x8000` | `partitions.bin` | MeowKit 16 MB 分区表 |
| `0xE000` | `boot_app0.bin` | Arduino 启动选择数据 |
| `0x10000` | `firmware.bin` | MeowKit 应用固件 |

发布流水线必须从同一次构建取得全部镜像，不得混用不同版本。安装前后都要校验哈希。

> 当前 `partitions_16mb.csv` 只有一个 12.5 MB 应用槽，无法提供带回滚保护的设备内 OTA。除非固件体积显著下降并重新规划双应用分区，否则 USB 下载模式应继续作为唯一受支持的更新方式。

### 3. 交互细节

- 包装内只放一句话和一个二维码：**更新或恢复 MeowKit：meowkit.dev/update**。
- 在 **Settings > About** 显示固件版本、硬件版本和“更新指南”二维码。
- 下载模式动画必须按真实顺序呈现：**关机并拔线 → 按住 BOOT 开机 → 等待 2 秒后松开 → 连接电脑**。
- 连接成功后显示设备名，不显示晦涩的串口术语。
- 失败信息给出下一步，例如“换一根数据线”，不要只显示错误码。
- 更新完成页明确写出：**拔线，关机，再开机**。

### 4. 开发者烧录

开发者仍可使用仓库中的 PlatformIO 配置：

```powershell
pio run
pio run --target upload
pio device monitor --baud 115200
```

执行 `upload` 前，同样需要让 MeowKit 进入下载模式。若电脑连接了多个串口设备，可在命令中指定端口：

```powershell
pio run --target upload --upload-port COM7
```

macOS 或 Linux 使用对应的 `/dev/...` 设备路径。

### 5. 上线验收

发布前至少验证：

- Windows 11、当前版 macOS、Ubuntu LTS
- Chrome 与 Edge
- 更新时保留 NVS 设置
- 恢复安装可修复空白 Flash 和损坏固件
- 更新中途拔线后可以重新进入下载模式并恢复
- 充电线、坏线、USB 扩展坞和端口被占用时，提示清楚可执行
- 固件版本与网页展示一致，所有下载文件的 SHA-256 一致
